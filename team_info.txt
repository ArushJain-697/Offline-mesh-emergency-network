Project Name - Offline Mesh Emergency Network (OMEN)

This project is a simple peer-to-peer mesh networking system that allows multiple laptops to communicate directly using their respective IP addresses. Every laptop in the network acts as an independent “node,” identified by a letter such as A, B, C, etc. Instead of using a central server, each node communicates directly with the others, forming a small mesh network where all communication is distributed.

Each node stores the IP address and port of every other known node inside a file called nodes.dat. When the program starts, it reads this file to determine which other laptops it can communicate with. A user can send a message to a specific node or broadcast a message to all nodes in the network.

One of the key features of this project is that new laptops can join the mesh network dynamically. When a new node wants to join, it provides its IP address and port to any one of the existing nodes (called the helper node). This helper node runs a small tool that broadcasts a special join message to all other nodes, informing them about the new node. The nodes.dat file on the other nodes is then updated so that it includes the IP address of the new node. After this, the new node is added to the mesh and can communicate with all other nodes.

The system is implemented using the following files:

mesh_cli.c - Provides the chat menu, handles user input, and displays incoming messages.

mesh_backend.c - Handles all networking: sending, receiving, auto-accepting new nodes, updating nodes.dat, and writing chat history.

mesh_backend.h - Defines the backend functions used by the chat interface.

nodes.dat – Stores all known node names, IP addresses, and ports for the mesh network.

Makefile – Compiles the chat program and runs commands like make chat and make add.

chat_history_*.txt - Automatically saved chat logs and system messages for each node. (* replaces nodes for example A,B,C....)

Overall, the project demonstrates how a decentralized communication system can be built without servers, using basic networking concepts. It shows message passing, broadcasting, and dynamic node discovery, all inside a small mesh network that expands as new nodes join. It is a working model of how distributed communication can function in environments like villages or disaster scenarios, where central servers may not be available.
